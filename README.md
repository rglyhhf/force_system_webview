# Force System WebView

强制 Android 应用使用系统 WebView，移除应用自带的私有网页内核（TBS X5 / U4 / d6 / MECO / XWeb 等），省空间 + 统一内核行为。

## 原理

- 通过 Magisk/KernelSU/APatch 模块方式运行，对 `/data/data/<pkg>` 下的私有内核目录做**备份 + 移除**（mv 到 `/data/adb/force_webview/backup/`，原位置放置 chmod 000 占坑文件防止重新下载）
- 关闭开关或卸载模块时按 config 中的完整相对路径**还原**，属主与 SELinux 上下文继承自应用根目录
- 还原路径只来自 config.json 的 dirs[]，绝不遍历备份树，避免误删

## 功能

- **概览页**：生效应用数、系统 WebView 版本、设备信息、备份占用与数据分区使用
- **应用管理**：搜索、批量启停、强停、生效状态
- **全机扫描**：检测所有带私有内核的应用（完整内核 / 组件残留 / 游戏分类），一键添加管控，扫描结果缓存
- **适配分级**：已适配（长期验证）/ 未验证 / 已知风险（微信、企业微信、高德地图）
- **返回手势**：弹层逐级关闭，不打断使用
- **WebUI**：Material 3 风格，深浅色跟随系统，沉浸式状态栏

## 环境要求

- Root（KernelSU / Magisk / APatch）
- Android 12+（WebView 更新机制依赖）

## 使用

1. 刷入模块（模块目录放入 `/data/adb/modules/`）
2. 在管理器中打开 WebUI
3. 「自动分析所有 APP」→ 查看哪些应用带私有内核 → 点卡片进详情 → 添加
4. 到「应用」页打开开关 → 应用配置

## 注意

- 部分应用页面可能出现加载异常，关闭对应开关即可恢复
- 应用更新后可能重新下载内核，重新应用配置即可
- 请勿在管控生效期间清除应用数据
